An entry for [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) on make.fun: one line, the funniest excuse an AI agent gives after failing a task.

## How it works

`main.py` writes a single line to `/output/entry.txt`. The program is fully
deterministic — it produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
